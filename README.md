# BOOTH — Pro DJ Supply

Tienda conceptual de equipamiento DJ de estándar de club (CDJ-3000, DJM-A9, XDJ-AZ, XDJ-RX3). Proyecto de portfolio: precios estimados en USD, checkout de demostración sin cobro real.

**Stack:** Next.js 16 (App Router, Cache Components) · React 19 · Tailwind CSS 4 · TypeScript · Vercel

- Hero con video en loop y grano animado
- Catálogo con filtros por categoría y fichas técnicas completas por producto
- Carrito persistente (localStorage) con drawer, cantidades y checkout demo
- Bundle "Club Booth" con descuento
- Páginas de producto prerenderizadas con `generateStaticParams`

```bash
npm install
npm run dev
```
